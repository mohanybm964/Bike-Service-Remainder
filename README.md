# 🚴‍♂️ Bike Service Reminder

A simple web application to help bike owners track and get reminders for their next bike service. Built using **HTML**, **CSS**, and **JavaScript**.

## 🌟 Features

- Add your bike's last service date.
- Automatically calculates the next service date.
- Visual reminders and alerts.
- Responsive and clean UI.
- Lightweight and runs entirely in the browser.

## 🛠 Tech Stack

- **HTML** – Structure
- **CSS** – Styling and layout
- **PHP** - Connecting database
- **JavaScript** – Logic for date calculation and reminders
